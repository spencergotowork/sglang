## 容易被ASR弄错或被混用的词

| 原始ASR常见写法 | 规范术语/解释 | 确定程度 |
|---|---|---|
| S档、SG浪、SGA | SGLang | 上下文高 |
| dispug、dbug | DSpark，投机解码实现/路径名称 | 上下文高，末段也提及DSpark |
| WordFi、WiFi、Wirefarm | verify / target verification，目标模型对草稿验证 | 上下文高 |
| interleave、英特利不、unbeliever | interleaved，交错布局 | 上下文高 |
| PoS PoI、pyspy | py-spy，进程外Python抓栈/采样工具 | 二次识别明确 |
| 站 | 栈，call stack | 上下文高 |
| 思索 | 死锁，deadlock | 上下文高；hang仍可能有其他原因 |
| HIGH SPARTS、Headspot | HiSparse，host完整KV+GPU热点工作集 | 上下文高 |
| staff、stab | step，一轮生成/验证步骤 | 上下文高 |
| qln、qln4 | q_len=4，query序列长度 | 上下文高 |
| Barsite、白菜 | batch size；需区分请求batch与本轮token数 | 上下文高 |
| miner bond、慢慢绷 | memory-bound，数据供应限制执行速度 | 上下文高 |
| Export | expert，MoE专家 | 上下文高 |
| RejectSupply、RelaxSupply | 疑似rejection sampling，拒绝/纠正采样 | 中；依据verify后与词表上下文 |
| 两个次表 | 两套词表/词表相关开销 | 中；不能据此断言具体kernel算法 |
| 系数化 | 稀疏化，sparsification | 上下文高 |
| CRR | 疑似CSR（Compressed Sparse Row） | 中；即使原意为CSR，也不准确描述cuSPARSELt结构化格式 |
| ACS/NCS | PPU厂商profiling工具与类似Nsight Systems的时间线工具 | 具体厂商名字未核实，不按精确工具名教学 |

TP/PP/CP/EP是分工维度；PCP/DCP是不同阶段的上下文并行；DSA中的Top-K选择历史token位置，MoE中的Top-K选择专家，投机参数中的topk可能是分支宽度，三个Top-K不是同一概念。
